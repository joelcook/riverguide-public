# CJK 0321 Intake and Release (N)

In this course students learn the intake and release procedures within correctional facilities. Emphasis is placed on inmate processing, identification, classification, and documentation. Topics include searches, property control, records management, and the application of policies and procedures to ensure accurate and secure intake and release operations.

16 hours

### Prerequisites

Acceptance into the Correctional Basic Recruit Academy program
