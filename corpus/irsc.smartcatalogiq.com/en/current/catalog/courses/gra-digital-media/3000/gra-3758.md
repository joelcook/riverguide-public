# GRA 3758 Scripting for Web Sites

In this course, students explore the fundamentals of creating web pages with a focus on design and aesthetics. Students create several html-css-based projects using the latest developments for the creation of websites which may include other scripting languages. Students are encouraged to create professional-level websites in this class.

3 credits
