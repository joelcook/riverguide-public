# CTS 4425 Web Application Development

This course shows how to use asp.net to process data from web pages. Students create n-tier asp.net web applications. Structured Query Language server databases are accessed and manipulated using ado.net. Students implement code that provides persistence of data between user requests.

3 credits

### Prerequisites

[ISM 3212](https://irsc.smartcatalogiq.com/en/current/catalog/courses/ism-computer-information-technology/3000/ism-3212), [CGS 1540](https://irsc.smartcatalogiq.com/en/current/catalog/courses/cgs-computer-science/1000/cgs-1540), [COP 2000](https://irsc.smartcatalogiq.com/en/current/catalog/courses/cop-computer-science/2000/cop-2000)
