# CTS 1205 Excel I

In this course, students acquire hands-on experience with the Microsoft Excel software application. Using an exercise-oriented approach, students become proficient in the application of Microsoft Excel. Students are recommended to have basic keyboarding skills.

3 credits

### Course Fee

Lab fee $20.
