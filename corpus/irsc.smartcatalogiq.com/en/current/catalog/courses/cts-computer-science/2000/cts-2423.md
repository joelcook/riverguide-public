# CTS 2423 .NET Application Development

In this course the students are introduced to the Microsoft .NET framework. Students develop the knowledge and skills to build desktop and web applications using Visual Basic (VB) and C Sharp (C#), the Microsoft .NET core languages. Students also review object-oriented programming concepts in VB and C#, and are then introduced to Windows Forms for desktop application development and ASP .NET Web Forms and MVC for web application development. Students are also exposed to ADO .NET technologies and the Entity Framework for implementing the data access layer.

3 credits
