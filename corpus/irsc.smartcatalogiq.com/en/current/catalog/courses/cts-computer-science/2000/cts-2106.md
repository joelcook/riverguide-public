# CTS 2106 Linux Fundamentals

In this course, students explore how to install and use fundamental commands and utilities of UNIX/Linux based operating systems. Students focus on system administration, hardware configuration, user management, and TCP/IP networking protocols.

3 credits

Lab fee $20.
