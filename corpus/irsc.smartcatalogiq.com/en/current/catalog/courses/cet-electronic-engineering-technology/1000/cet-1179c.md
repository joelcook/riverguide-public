# CET 1179C A+ Certification Software

In this course, students apply the practical skills needed to install, configure, troubleshoot, and secure modern operating systems including Microsoft Windows, MacOS, Linux, and mobile operating systems in preparation for entry-level IT support roles. Aligned with the current objectives of the CompTIA A+ Core 2 (Software) certification, the course emphasizes hands-on learning and real-world problem-solving as students develop proficiency in using command-line tools and system utilities; managing users, permissions, and system settings; and diagnosing common software and performance issues.

3 credits

### Prerequisites
