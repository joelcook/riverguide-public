# COP 2830 Web Programming

In this course, students examine the fundamentals of web programming to produce modern Web pages and Web-based applications. Students explore Web page design, server and client-side scripting, and the essentials of electronic commerce. Additional topics may include HTML, CSS, and scripting languages such as JavaScript.

3 credits

Lab fee $20.
