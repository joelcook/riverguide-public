# ETD 2551 Computer Aided Drafting - Civil

In this course, students explore how to develop civil engineering drawings using the current AutoCAD Civil Engineering application software. Students learn terminology and complete tutorials and drawing assignments that include real-world examples in the field of civil engineering. Command of the application software is stressed along with file management and plotting techniques.

3 credits

### Prerequisites

[ETD 1320](https://irsc.smartcatalogiq.com/en/current/catalog/courses/etd-drafting-and-design-technology/1000/etd-1320) with grade of 'C' or higher
