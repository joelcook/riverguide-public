# ISM 3212 Database Design and Administration

In this course, student explore fundamental concepts of data modeling and database design. Students study specific concepts pertaining to relational database model, manipulating data using SQL (Structured Query Language) and database administration.

3 credits

### Prerequisites

[CGS 1540](https://irsc.smartcatalogiq.com/en/current/catalog/courses/cgs-computer-science/1000/cgs-1540)
