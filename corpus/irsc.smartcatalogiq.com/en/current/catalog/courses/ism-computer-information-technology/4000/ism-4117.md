# ISM 4117 Data Mining and Data Warehousing

In this course the students examine the techniques of data mining and the implementation and benefits of data mining for industries such as retail, target marketing, fraud protection, health care, web, and e-commerce are examined. Students also analyze detailed case studies using current mining tools on real data.

3 credits

### Prerequisites

[ISM 3212](https://irsc.smartcatalogiq.com/en/current/catalog/courses/ism-computer-information-technology/3000/ism-3212), [CGS 1540](https://irsc.smartcatalogiq.com/en/current/catalog/courses/cgs-computer-science/1000/cgs-1540)
