# CIS 4200 Penetration Testing

In this course, students evaluate real-world penetration testing in a hands-on and gamified manner. Students discover methodologies to seek vulnerabilities in machines and learn how to use industry-standard tools to exploit those vulnerabilities. Topics include reconnaissance, scanning and enumeration, vulnerability analysis, exploitation, post-exploitation techniques, and reporting. Students will work in controlled lab environments to apply offensive security concepts ethically and legally, building practical skills aligned with professional penetration testing engagements.

3 credits
