# CGS 4828 Advanced Web Design

This course presents advanced concepts in Web design, including interactivity and animation. It is for students who have mastered the skills of building a basic Web site and want to advance to more sophisticated interface design and techniques. Students are challenged to solve advanced communication problems while addressing technical issues related to Web design and user experience. An emphasis is placed on Web standards, advanced HTML and CSS, usability and aesthetics. Students work with industry standard tools to produce or simulate real world projects.

3 credits
